# TeCoBots

Project website for TeCoBots, modular tensegrity continuum robots that bend, collapse, and team up by docking.

**Live site:** https://tecobot.github.io

- **Overview:** what the robots do, with short clips and videos
- **Play:** interactive 3D configurations, from one robot to six docked together
- **Paper:** the paper, figure by figure

Paper: [*Nature Machine Intelligence* (2026)](https://www.nature.com/articles/s42256-026-01335-4) · [arXiv:2608.27221](https://arxiv.org/abs/2608.27221) · Code: [github.com/mahmud-hasans/TeCoBot](https://github.com/mahmud-hasans/TeCoBot)
