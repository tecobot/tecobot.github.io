# TeCoBot website

The project site for *Tensegrity Continuum Robots Enable Task-Adaptive Morphologies for Cooperative Behaviors*. Plain HTML, CSS and JavaScript, so there is no build step. Every page also works opened straight from your computer.

## What's here

| Path | Page |
|---|---|
| `index.html` | Project page: hero, reels, abstract, results, videos, figures, citation |
| `play/index.html` | Play with TeCoBots, the interactive configuration browser |
| `paper/index.html` | Paper: title, authors, affiliation, then Figures 1–6 with plain-language explainers and the citation |
| `build/index.html` | Build guide: specs, bill of materials, CAD, assembly, model, gaits |
| `assets/tecobot.js` | Robot geometry and renderer, shared by the hero and Play. All dimensions are in the `MM` block at the top. |
| `assets/tecobot.css` | Renderer and Play styles |
| `assets/site.css`, `assets/site.js` | Page layout, clips, video library, lightbox |
| `media/clips/` | Short muted loops (from the GIFs) |
| `media/video/` | Full videos, 720p |
| `media/figs/` | Paper figures: full size, `-md` and `-sm` versions, and crops used in the guide |
| `cad/` | Put STL files here |

`play/#M1`, `play/#dock33` and so on open Play on that configuration.

## Putting it online

The site lives at **https://tecobot.github.io**, served from the repository `tecobot/tecobot.github.io` in the TeCoBot organization.

1. Put the contents of this folder (not the folder itself) at the top level of `tecobot/tecobot.github.io`. The easiest way is **GitHub Desktop**: clone the repository, copy these files into the cloned folder, then commit and push. The site has 127 files, and the browser upload takes at most 100 at a time (the `media` folder alone has 116), so a browser upload would need several rounds that keep the folder structure intact. Every file is under the 25 MB limit.
2. Open the repository's **Settings → Pages**, choose **Deploy from a branch**, pick `main` and `/ (root)`, and save.
3. The site appears at `https://tecobot.github.io` within a couple of minutes.

The `.nojekyll` file tells GitHub to serve the files exactly as they are. All links inside the site are relative, so it works at this address, or any other, without changes. The full address appears only in `index.html`'s link-preview tags (`og:url`, `og:image`, `canonical`); update those if the site ever moves.

The code stays at `github.com/mahmud-hasans/TeCoBot`, which is where the paper points.
